T-PLAYER 2.1

Android-first музыкальный плеер прямо поверх мобильного сайта: аудиореактивные волны, Liquid Glass full-screen, эквалайзер, Bass Boost, crossfade, Smart Library, скорость, таймер сна, история, очередь и плейлисты. Работает в обычном Chrome через закладку.

1. Установка T-PLAYER

Установка добавляет эту страницу как PWA. Для управления музыкой на сторонних сайтах всё равно используется закладка ниже.

2. Скопируйте закладку

Короткая подгружает плеер с этого сайта. Если на нужном сайте после запуска ничего не появилось (сайт запрещает внешние скрипты), используйте автономную: весь код лежит внутри закладки.

3. Создайте закладку в Chrome

  1. Откройте любую страницу, нажмите ⋮ → ☆ (Добавить закладку).
  2. Нажмите на созданную закладку для редактирования (или «Изменить»).
  3. В поле Название впишите плеер.
  4. В поле URL вставьте скопированный код (он начинается с javascript:) и сохраните.

4. Запуск на сайте с музыкой

  1. Откройте страницу с треками.
  2. В адресной строке начните вводить плеер и выберите закладку из подсказок (значок ☆).
  3. Появится плавающая кнопка. Её можно перетащить, она прилипает к краю.

Повторный запуск закладки скрывает или показывает плеер. Пока плеер на странице, переходы по ссылкам сайта не прерывают музыку.

Проверить на демо-странице

В меню доступны полноэкранный режим, эквалайзер и Bass Boost для same-origin треков, crossfade, Smart Library, скорость воспроизведения, таймер сна и история. Аудиореактивность зависит от поддержки captureStream() браузером; при отсутствии поддержки работает анимированный fallback.
