# Spaces Float Player

Плавающий плеер для мобильных сайтов: круглая кнопка ▶/⏸ и рядом кнопка с тремя точками, которая раскрывает меню
(текущий трек, перемотка, предыдущий/следующий, перемешать, повтор, список треков страницы и очередь).
Кнопки можно перетаскивать, они прилипают к краю экрана.

Основа и идея: Spaces Cyber Player © @https (https://spcs.me). Подпись автора оставлена в шапке меню.

## Почему не расширение

Обычный Chrome на Android не поддерживает расширения, поэтому плеер сделан одним скриптом `float-player.js`,
который работает прямо в странице. Его можно запускать:

1. **Закладкой** в обычном Chrome на телефоне (основной способ, ниже).
2. **Расширением** (`manifest.json`) в браузерах с поддержкой расширений: Kiwi, Vivaldi, десктопный Chrome.
   Распакуйте папку, включите режим разработчика, «Загрузить распакованное».

## Хостинг (бесплатно, GitHub Pages) — с телефона

1. На github.com создайте репозиторий `float-player` (Public).
2. **Add file → Upload files**, выберите `index.html`, `float-player.js`, `float-player.min.js`, `demo.html`. Commit.
3. **Settings → Pages → Branch: main / root → Save**. Через минуту сайт будет по адресу `https://ВАШ_НИК.github.io/float-player/`.
4. Откройте этот адрес в Chrome и следуйте инструкции на странице: скопировать закладку, создать закладку, запускать по имени из адресной строки.

Подойдёт и Cloudflare Pages / Netlify (загрузка папки или zip) — файлы те же.

## Как это работает

- Треки берутся со страницы из блоков `.player_item[data-src]` (как в исходном расширении). Если таких нет,
  ищутся `<audio>` и ссылки на mp3/m4a/ogg/wav/flac.
- Звук играет через `Audio` в самой странице. Пока плеер на странице, переходы по ссылкам того же сайта и GET-формы
  выполняются без перезагрузки (подмена содержимого страницы), поэтому музыка не прерывается.
  Переключатель «Не прерывать музыку при переходах» в меню отключает это, если сайт ведёт себя странно.
- Управление с экрана блокировки и из шторки уведомлений (Media Session), работа при выключенном экране.
- Очередь, позиция трека, режимы и положение кнопки запоминаются в `localStorage` сайта.
- Когда начинает играть плеер, родной плеер сайта ставится на паузу.

## Ограничения

- Закладку надо запускать на каждой «жёсткой» загрузке страницы (обновление, закрытая вкладка). Пока вкладка жива и плеер
  включён, переходы по сайту её не сбрасывают.
- POST-формы и страницы с другим набором скриптов открываются обычным способом (с перезагрузкой): музыка при этом
  останавливается, очередь и позиция сохраняются.
- Ссылки на треки на Spaces могут быть временными: если трек не грузится, обновите страницу.

## Файлы

- `float-player.js` — сам плеер (исходник).
- `float-player.min.js` — однострочная версия для автономной закладки (`node build.js`).
- `index.html` — страница установки. `demo.html` — демо с тестовыми треками.
- `manifest.json` — для запуска как расширение (Kiwi, Vivaldi, десктоп).
